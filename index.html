Why I Built This

Many deaf and hard-of-hearing people in India use Indian Sign Language (ISL). Trained interpreters are hard to find, and that makes school, hospital visits and jobs harder than they should be.

I wanted to see how far a computer can get with the first step: reading a hand sign from a picture and turning it into a letter. It won't replace an interpreter. It's a small step towards tools that make communication easier.

Hospital Visits

Helping patients communicate immediate symptoms and understand prescriptions.

School & Learning

Assisting students in educational settings where certified interpreters are scarce.

Jobs & Daily Life

Enabling independent communication in interviews, banking, and public counters.

The Model, Layer by Layer

A small custom CNN with 4 blocks. Each block does the same three jobs, using more filters each time.

01

Input

A 128×128 colour photo. Pixel values are scaled to 0–1.

02

Conv blocks ×4

32, 64, 128, then 256 filters. Each block finds patterns, steadies the learning (BatchNorm), and shrinks the image (MaxPool).

03

Global Average Pooling

Turns the final feature maps into 256 numbers. It uses far fewer weights than Flatten, so it overfits less.

04

Dense + Dropout

256 units that combine the clues. Dropout (0.4) randomly switches some off during training so the model doesn't just memorise.

05

Softmax

24 outputs, one per letter, adding up to 100%.

Total Parameters: 463,320 parameters (about 1.76 MB), small enough to run fast. The Adam optimiser trains it, and the learning rate drops automatically when progress stalls.
